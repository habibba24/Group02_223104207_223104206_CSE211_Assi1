Mission statement:-The mission of this Web Programming course is to equip students with the essential skills to design and build modern, accessible, and standards-compliant websites. Through hands-on practice with HTML, CSS, and JavaScript, learners develop problem-solving abilities, user-centered design awareness, and the foundation needed to thrive in the rapidly evolving web development field.

Introduction to web programming course

This course introduces students to the principles and practices of modern web application development. The curriculum covers the complete lifecycle of building web applications, from design and front-end implementation with HTML5 and CSS3, to adding interactivity with JavaScript, and developing dynamic front-end applications using React. On the server side, students will use Node.js and the Express.js framework to design and implement RESTful APIs, integrate with relational databases (SQLite/Postgres), and manage data-driven workflows. Emphasis is placed on responsive design, accessibility, security, and industry-standard development tools and practices. By the end of the course, students will have built and deployed a full-stack web application to the cloud, gaining both practical skills and real-world project experience.

Course Objectives

  1. Understand the basics of web technologies and architecture.
  2. Learn to create web pages using HTML and style them with CSS.
  3. Develop interactive web applications using JavaScript.
  4. Gain knowledge of server-side programming and databases.
  5. Implement best practices for web development, including responsive design and accessibility.
  6. Build and deploy a complete web application as a final project.

Topics covered

  • Internet and world wide Web
  • client/server architecture
  • Design considerations
  • HTML Basics
  • HTML5 advanced Topics
  • HTML tables and forms
  • Database Integration

course benefits

Upon successful completion of this course, students will be able to:

  • Design and develop responsive, and semantically structured websites using modern HTML5 and CSS3, including Flexbox and Grid layouts, and responsive design techniques.
  • Implement interactivity with modern JavaScript (ES6+), including the Document Object Model (DOM) manipulation, events, form validation, API integration, and create interactive user experiences.
  • Build front-end applications using React with components, state management, and client-side routing.
  • Develop server-side applications and RESTful APIs using Nodejs and the Express framework.
  • Integrate databases (SQLite/Postgres) with web applications to perform Create, Read,Update, and Delete (CRUD) operations.
  • Apply web standards including the fundamentals of HTTP, accessibility guidelines (WCAG 2.2), and web security practices (HTTPS, CORS, authentication, JWT).
  • Use modern development tools and workflows, including Git/GitHub for version control, VS Code for development, and deployment pipelines for cloud-based applications.
  • Evaluate and optimize web applications for performance and user experience using CoreWeb Vitals and accessibility audits.
